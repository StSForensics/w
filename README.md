# STS Forensics and O4M public website

Source for the public site at https://stsforensics.github.io/w/

## What this is

One static page (index.html, styles.css, app.js, assets/) presenting O4M Record Tests 2026 v1.0 and the two free exercises, Ask the Record and Find the Gap. The page has no sign-up and no uploads. It loads its fonts from Google Fonts. app.js drives the small illustration at the top, which uses made-up events and is not output from the O4M verifier.

## Preview

Open index.html in a browser, or run `python3 -m http.server` in this folder. There is no build step.

## Scope note

Completeness is measured within a declared, independently observable boundary. A record can reveal gaps within what was sealed. An event that never reached the record cannot be found from the record alone, so an independent reference is needed.
