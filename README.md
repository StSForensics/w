# STS Forensics and O4M website

One static page for sts-forensics.com and o4m.ai. It explains the O4M Record Tests (open requirements for checking AI records from outside), links two free exercises, and says how to comment or get in touch.

## What is here

- index.html, styles.css, app.js: the page. No build step and no framework. app.js drives the small illustration in the hero, which uses made-up events and is not output from the O4M verifier.
- assets: logo, favicon and the social preview image.
- sitemap.xml and robots.txt.

## Preview

Open index.html in a browser, or run `python3 -m http.server` in this folder.
